# ひみつきちつくろ

森を歩いて資源を集め、秘密基地を育てるブラウザゲームです。インストールは不要で、スマートフォンの縦画面とパソコンの両方で遊べます。

公開ページ: https://geo-go-gb.github.io/forest-base/

リポジトリの **Settings > Pages > Source** を **GitHub Actions** にしてください。既定ブランチ（main）へ入ったあと、上の URL で遊べます。Source が GitHub Actions になるまでは、その URL はまだ開きません。

## 遊び方

1. 始める（セーブがあれば「続きから」）。
2. 画面の好きな場所を触るとスティックが出る。パソコンは WASD・矢印キー。枝・小石・木の実は近づくと拾える。
3. 秘密基地に戻ると、持ち物が保管にしまう。
4. 「売る」でコインにして、「建てる」「仲間」で拠点を便利にする。
5. 北の光る林では、光るキノコをボタンで拾う。自動では拾えない。
6. ゲームを閉じているあいだは、生産は進まない。

## 1. 実装した遊びと今回の完成範囲

短時間で一通り遊べる縦切りです。

- ひとつの森マップと、ひとつの秘密基地。
- 移動（触った場所に出るスティック、WASD、矢印キー）と、一般資源3種（枝、小石、木の実）の自動回収。
- 特別な資源（光るキノコ）は光と「特別」で区別し、近くのボタンで拾う。
- 売却とコイン。材料とコインに上限はない。作業台で品物を作り、お店に飾るとお客さんが買っていく。
- 作業台（枝→木材と、品物づくり）、研究机（発見で解放）。
- 枝拾いおじさん、石拾いさん、木の実拾いさんが、開いているあいだだけ拾って基地に届ける。作業職人が品を作り、店番が台に飾る。
- 枝が足りない、保管がいっぱい、のときは理由と直し方を表示する。
- 光るキノコを見つけると、研究机を建てられる。
- LocalStorage にバージョン付きで保存し、再読み込みで復元する。壊れたセーブでは新規に起動する。

広告、ガチャ、課金、オフライン進行、複数拠点はありません。地面、道、光る林、水辺、小屋、人物、木、花、拾う物は、承認済みの絵（`assets/`）です。ファイルが読めないキーだけ、図形に戻ります。

おえかき: https://geo-go-gb.github.io/forest-base/draw/

## 3. 起動手順

ビルドは不要です。静的ファイルを配信します。

```bash
python3 -m http.server 8080
```

ブラウザで http://localhost:8080 を開きます。おえかきは http://localhost:8080/draw/ です。パスは相対なので、GitHub Pages の `/forest-base/` でもそのまま動きます。

開発用のロジック確認:

```bash
node tests/logic.test.js
```

## 4. 実施した確認と結果

Chrome で次を通し、成功しました。

- タイトルと見出しが「ひみつきちつくろ」である。画面の文言は漢字とカタカナを混ぜた日本語。
- 矢印キーで移動する。画面を押しているあいだだけ、その場所に半透明のスティックが出る。離すと消える。ボタンを押してもスティックは出ない。
- 近づくと枝・小石・木の実が持ち物に入り、秘密基地で保管にしまう。
- 「売る」でコインが増える。
- 作業台を建てると、マップの拠点に形が出る。
- 仲間を雇うと、開いているあいだに歩いて材料を届ける。コインで速さ、持てる数、人数を上げられる。
- 枝を売り切ると「作業台: 枝が足りない」と、直し方（拾うか、枝拾いおじさんを雇う）が出る。材料とコインに上限はない。
- 光るキノコは歩くだけでは消えず、ボタンで拾うと発見になり、研究机が「建てる」に変わる。
- 再読み込み後、「続きから」でコイン、建物、雇用、発見が戻る。
- 保存時刻を 24 時間前に書き換えて読み込んでも、資源も作業の途中経過も増えない。
- 幅 390px・devicePixelRatio 3 で、プレイヤーは画面の中央付近、地図は旧ズーム（1.62）より広い。キャンバスの CSS サイズはビューポートのままで、内部解像度で引き伸ばされない。
- 同じ画面で、ビューポートは `maximum-scale=1` と `user-scalable=no`。キャンバスは `touch-action: none`。ダブルタップとピンチ用の gesture イベントは既定動作を止める。
- 360×640、375×667、390×844、414×896、430×932、タブレット 768×1024、およびそれぞれの横画面で、ヘッダー、ボタン、通知、吹き出し、売るパネルが重ならず、画面の外に切れない。スティックは触っているときだけ出る。
- 絵を描く画面を幅 390px で開き、「主人公（正面）」と「1/18」が出る。指の代わりのポインタで線が描け、ペンの太さと色を変えられる。次へ進める（空でも止められない）。再読み込みで、描いた絵が残る。「まとめて保存」の ZIP に、描いた PNG と `manifest.json` が入る。
- 幅 390px・devicePixelRatio 3 で、地面・道・光る林・池・小屋が絵になる。矢印キーで歩きの 4 方向が変わり、右向きは左の反転。池、小屋の壁、木の幹は通り抜けない。光るキノコは光り、拾う物はきらめく。
- 絵が無いキーは図形のまま。`assets/player.png` を外すと、主人公だけ図形に戻る。

`node tests/logic.test.js` も成功しています。音はありません。実機の iOS Safari での指操作は、この環境では未実施です。おえかきの保存用 JSZip 3.10.1 だけ、描く画面が CDN から読みます。ゲーム本体は CDN を使いません。

## 5. 採用した仮定と、調整できる数値

数値はすべて `js/config.js` です。

- 建築は自由配置にせず、秘密基地の決まった位置に建てる。ドラッグ配置はスティックとぶつかり、誤タップが増えるため。
- 売る、建てる、雇う、リュックを買うのは、秘密基地の範囲（拠点の中心から半径 120）だけ。白い円は描かず、小屋の絵で示す。見ることは外でもできる。
- 縦画面を基本にした。横画面ではボタンを下段いっぱいまで並べる。スティックは指の位置にだけ出るので、常設の場所は取らない。
- カメラはプレイヤーを中央に置く。地図の端では、はみ出さない範囲で止める。倍率は `camera.phone` / `tablet` / `desktop`（幅 390 前後は 1.0。以前の 1.62 より引いている）。
- ページそのものの拡大は止める。viewport の `maximum-scale=1` と `user-scalable=no`、キャンバスの `touch-action: none`、`gesturestart` とダブルタップの `preventDefault`。iOS が `user-scalable=no` を無視しても、あとの二つでピンチとダブルタップを止める。Phaser の `resolution` は 1 に固定し、倍率は CSS ピクセルの幅で決める。
- 生産は表示中のフレームだけで進む。タブが隠れているときは 0。1 フレームに足す時間は最大 100ms（`maxFrameMs`）。`savedAt` は「いつ保存したか」の表示だけで、経過時間は生産に足さない。
- セーブは小さい JSON なので LocalStorage。形式バージョンは 1。読めないデータは隔離して新規に始める。より新しい形式は上書きしない。IndexedDB は、データが重くなってからで足りる。
- 絵の一覧は `js/sprites.js`。ゲームは起動時に `assets/{キー}.png` を読み、読めないキーだけ図形を描く。表示倍率は `config.js` の `art`（人物 0.55、木 1.4、小屋 1.25、拾う物は種類ごと、花と石と家具は 1）。地面は `ground_grass`、道は `ground_path`、光る林は `ground_dark`、水辺は `water_edge`。歩きは 4 方向・14fps（右は左の反転）、待機は 2fps、木と花の揺れは 0,1,0,2 を 3fps。人物の足元に 28×8 の影を描き、足元の y で前後を並べる。光るキノコの光と、拾う物のきらめきはコードで足す。
- おえかきの下描きは、ゲームのセーブとは別の LocalStorage（`himitsukichi-draw-v1`）に残る。かいた PNG の背景は透明で、うしろの市松は画面だけ。
- Phaser は 3.85.2 を `vendor/phaser.min.js` に固定した。MIT。ゲームの実行時に外部 CDN はない。おえかきの ZIP 作成だけ JSZip 3.10.1 を固定 URL で読む。

手触り: 移動 110（人物の表示倍率での世界座標 px/s）、自動回収の半径 48。所持も保管もコインも上限はない。枝拾いおじさんは枝の場所まで歩いて拾い、基地に届けると保管が増える。石と木の実も同じ。作業職人は作業台で品を作り、店番はお店に飾る。秘密基地に戻ると、持っていた物がひとつずつ左上へ飛んで、保管の数が増える。作業台は 2.5 秒で枝 2 を木材 1 にし、竹とんぼなどの品も作れる。飾った品は、開いているあいだにお客さんが買ってコインになる。数の表示は 999、1.2k、3.4M、5.6G、7.8T。左上にコインと材料の数を出す。小屋の壁、木の幹、池には当たり判定がある。

## 6. 既知の制約と、次に進めるとよい段階

- 承認済みの絵は入っている。音はない。読めないファイルだけ図形に戻る。
- 仲間は枝、小石、木の実、作業台、お店の五人まで。人数はコインで増やせる。長い生産列や、別の地形はない。
- 研究机は発見の到達点で、その先の精錬や研究は未実装。
- 拠点は 1 つ。川辺、洞窟、遺跡はない。
- セーブはこのブラウザの中だけ。端末をまたがない。
- 実機のノッチやホームインジケータは safe-area を見ているが、実機での最終確認は残っている。

次は、きのこ以外の「道具が要る資源」、運搬と加工の詰まり、北以外の地形、の順が自然です。
