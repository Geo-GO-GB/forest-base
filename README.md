# ひみつきちつくろ

森を歩いて資源を集め、秘密基地を育てるブラウザゲームです。インストールは不要で、スマートフォンの縦画面とパソコンの両方で遊べます。

公開ページ: https://geo-go-gb.github.io/forest-base/

リポジトリの **Settings > Pages > Source** を **GitHub Actions** にしてください。既定ブランチ（main）へ入ったあと、上の URL で遊べます。Source が GitHub Actions になるまでは、その URL はまだ開きません。

## 遊び方

1. はじめる（セーブがあれば「つづきから」）。
2. したのスティック、または WASD・やじるしキーで歩く。えだ・こいし・きのみは近づくとひろえる。
3. ひみつきちの白い円の中へ戻ると、もちものがほかんにしまう。
4. 「うる」でコインにして、「たてる」「なかま」で拠点を便利にする。
5. 北のひかりのはやしでは、ひかるきのこをボタンでひろう。自動ではひろえない。
6. ゲームを閉じているあいだは、生産は進まない。

## 1. 実装した遊びと今回の完成範囲

短時間で一通り遊べる縦切りです。

- ひとつの森マップと、ひとつのひみつきち。
- 移動（仮想スティック、WASD、矢印キー）と、一般資源3種（えだ、こいし、きのみ）の自動回収。
- 特別な資源（ひかるきのこ）は光と「とくべつ」で区別し、近くのボタンでひろう。
- 売却とコイン。ちいさなりゅっくで所持容量アップ。
- きばこ（保管増）、さぎょうだい（えだ→もくざい）、けんきゅうづくえ（発見で解放）。
- きこりが、ゲームを開いているあいだだけえだをほかんに入れる。さぎょうだいがもくざいにする。
- えだが足りない、ほかんがいっぱい、のときは理由と直し方を表示する。
- ひかるきのこを見つけると、けんきゅうづくえを建てられる。
- LocalStorage にバージョン付きで保存し、再読み込みで復元する。壊れたセーブでは新規に起動する。

広告、ガチャ、課金、オフライン進行、複数拠点はありません。絵は図形の仮素材です。同じ仮素材を一枚ずつ手描きして、PNG を `assets/` に置くと差し替わります。

おえかき: https://geo-go-gb.github.io/forest-base/draw/

## 3. 起動手順

ビルドは不要です。静的ファイルを配信します。

```bash
python3 -m http.server 8080
```

ブラウザで http://localhost:8080 を開きます。おえかきは http://localhost:8080/draw/ です。パスは相対なので、GitHub Pages の `/forest-base/` でもそのまま動きます。

開発用のロジック確認:

```bash
node tests/logic.test.js
```

## 4. 実施した確認と結果

Chrome で次を通し、成功しました。

- タイトルと見出しが「ひみつきちつくろ」である。
- スティックと矢印キーで移動する。
- 近づくとえだ・こいし・きのみがもちものに入り、拠点の円でほかんにしまう。
- 「うる」でコインが増える。
- きばことさぎょうだいを建てると、マップの拠点に形が出る。
- きこりを雇うと、開いているあいだにえだが増える。
- えだを売り切ると「さぎょうだい: えだがたりない」と、直し方（ひろうか、きこりをやとう）が出る。ほかんがいっぱいのときも生産が止まり、売るかきばこを建てると再開できる。
- ひかるきのこは歩くだけでは消えず、ボタンで拾うと発見になり、けんきゅうづくえが「たてる」に変わる。
- 再読み込み後、「つづきから」でコイン、建物、雇用、発見が戻る。
- 保存時刻を 24 時間前に書き換えて読み込んでも、資源も作業の途中経過も増えない。
- 幅 390px の画面で、スティックと右側のボタンは重ならず、ボタンの高さは 48px 以上。
- 360×640、375×667、390×844、414×896、430×932、タブレット 768×1024、およびそれぞれの横画面で、ヘッダー、ボタン、スティック、通知、吹き出し、売るパネルが重ならず、画面の外に切れない。
- おえかきを幅 390px で開き、「主人公（正面）」と「1/19」が出る。指の代わりのポインタで線が描け、ペンのふとさと色を変えられる。つぎへ進める（空でも止められない）。再読み込みで、かいた絵が残る。「まとめて保存」の ZIP に、かいた PNG と `manifest.json` が入る。
- PNG が無いときは図形のまま。`assets/player.png` を置くと主人公だけ絵になり、ファイルを戻すと図形に戻る。

`node tests/logic.test.js` も成功しています。音はありません。実機の iOS Safari での指操作は、この環境では未実施です。おえかきの保存用 JSZip 3.10.1 だけ、描く画面が CDN から読みます。ゲーム本体は CDN を使いません。

## 5. 採用した仮定と、調整できる数値

数値はすべて `js/config.js` です。

- 建築は自由配置にせず、ひみつきちの決まった位置に建てる。スマートフォンでドラッグするとスティックとぶつかり、誤タップが増えるため。
- 売る、建てる、雇う、リュックを買うのは、拠点の白い円の中だけ。見ることは外でもできる。
- 縦画面を基本にした。横画面ではボタンを下段に並べ、スティックと重ならないようにしている。専用の横レイアウトはない。
- 生産は表示中のフレームだけで進む。タブが隠れているときは 0。1 フレームに足す時間は最大 100ms（`maxFrameMs`）。`savedAt` は「いつ保存したか」の表示だけで、経過時間は生産に足さない。
- セーブは小さい JSON なので LocalStorage。形式バージョンは 1。読めないデータは隔離して新規に始める。より新しい形式は上書きしない。IndexedDB は、データが重くなってからで足りる。
- 絵の一覧は `js/sprites.js`。ゲームは起動時に `assets/{キー}.png` を読み、読めないキーだけ図形を描く。地面、道、はやしの円、回収の輪、浮き文字は絵ではない。
- おえかきの下描きは、ゲームのセーブとは別の LocalStorage（`himitsukichi-draw-v1`）に残る。かいた PNG の背景は透明で、うしろの市松は画面だけ。
- Phaser は 3.85.2 を `vendor/phaser.min.js` に固定した。MIT。ゲームの実行時に外部 CDN はない。おえかきの ZIP 作成だけ JSZip 3.10.1 を固定 URL で読む。

仮の手触り: 移動 190、自動回収の半径 48、初期のもちもの 8、リュックで 18、ほかん 16、きばこで +28。きこりは 2 秒ごとにえだ 1。さぎょうだいは 2.5 秒でえだ 2 をもくざい 1 にする。短い探索で「拾う → 使う → 拠点が変わる → 北が気になる」まで届くようにしてある。

## 6. 既知の制約と、次に進めるとよい段階

- リポジトリに置いてある絵は、まだ図形。手描き PNG を `assets/` に入れると、そのキーだけ差し替わる。音はない。
- 仲間はきこり 1 人。運搬係や、入力待ちで止まる長い生産列はまだない。
- けんきゅうづくえは発見の到達点で、その先の精錬や研究は未実装。
- 拠点は 1 つ。川辺、洞窟、遺跡はない。
- セーブはこのブラウザの中だけ。端末をまたがない。
- 実機のノッチやホームインジケータは safe-area を見ているが、実機での最終確認は残っている。

次は、おえかきで描いた PNG を `assets/` に入れること、きのこ以外の「道具が要る資源」、運搬と加工の詰まり、北以外の地形、の順が自然です。
